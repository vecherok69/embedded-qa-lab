# BUG-002: Raspberry Pi 3 B+ працює в режимі undervoltage і тротлінгу при живленні від USB-порту ПК

| Поле | Значення |
| --- | --- |
| Severity / Priority | Major / High (дефект конфігурації стенда: під ризиком стабільність і SD-карта, результати всіх подальших тестів недостовірні) |
| Виріб / плата, ревізія, серійний номер | Raspberry Pi 3 Model B Plus Rev 1.3 |
| Версія прошивки (або хеш) | Raspberry Pi OS Lite (64-bit), чиста установка через Raspberry Pi Imager |
| Відтворюваність | 1 з 1 (стабільно при живленні від ПК) |
| Дата | 2026-10-31 |

## Стенд

- Схема підключення: тільки живлення micro-USB, мережа через Wi-Fi 2,4 ГГц, доступ по SSH (`pi3lab.local`). Периферії на GPIO немає.
- Живлення: **до** — USB-порт ПК через кабель micro-USB; **після** — окремий блок живлення 5 В / 3 А.
- Прилади та налаштування: `vcgencmd get_throttled`, мультиметр ANENG SZ08 (DC V, межа 20 В), візуальний контроль світлодіодів PWR (червоний) і ACT (зелений).
- Температура / середовище: кімнатна.

## Кроки відтворення

1. Записати на SD-карту Raspberry Pi OS Lite (64-bit) з увімкненим SSH і Wi-Fi.
2. Живити Raspberry Pi 3 B+ від USB-порту ПК кабелем micro-USB.
3. Спостерігати за світлодіодом PWR під час завантаження.
4. Після завантаження зайти по SSH і виконати `vcgencmd get_throttled`.

## Очікуваний результат

- Червоний PWR світиться постійно.
- `throttled=0x0` (не було ні просідання напруги, ні тротлінгу).
- На пінах 2/4 ↔ GND напруга 4,75–5,25 В.

## Фактичний результат

- PWR світиться на початку, потім згасає (на Pi 3 B+ це індикатор напруги нижче ≈4,63 В); ACT мигає, тобто плата завантажується.
- `throttled=0x50005`:
  - біт 0 — undervoltage **зараз**;
  - біт 2 — тротлінг процесора **зараз**;
  - біт 16 — undervoltage був з моменту завантаження;
  - біт 18 — тротлінг був з моменту завантаження.
- Мережа при цьому працює (`ping` 0 % втрат), тобто дефект прихований: зовні плата виглядає робочою.

## Докази

- Вивід `vcgencmd get_throttled` до заміни: `throttled=0x50005`, [pwr-throttled-0x50005.png](../screenshots/pwr-throttled-0x50005.png).
- Вивід після заміни: `throttled=0x0` (додається вивід `setup.sh`, де видно `throttled=0x0`).
- Заміри після заміни: див. [day1-power-gpio.md](../measurements/day1-power-gpio.md), PWR-01…PWR-02a.

## Перевірка виправлення

Заміна джерела на окремий блок 5 В:

| Перевірка | До (USB ПК) | Після (блок 5 В / 3 А) |
| --- | --- | --- |
| Світлодіод PWR | згасає після старту | світиться постійно |
| `vcgencmd get_throttled` | `0x50005` | `0x0` |
| 5 В, пін 2 ↔ пін 6 | не міряли | 5,00 В |
| 5 В, пін 4 ↔ пін 6 | не міряли | 4,98 В |
| 3,3 В, пін 1 ↔ пін 6 | не міряли | 3,29 В |

Статус: **виправлено** (заміна джерела живлення).

## Додатково

- Причина: USB-порт ПК розрахований на 0,5–0,9 А (USB 2.0/3.0), а Pi 3 B+ під час завантаження споживає до ≈1–1,3 А; плюс втрати на кабелі.
- Обхідний шлях: тільки окремий блок 5 В від 2,5 А і короткий товстий кабель.
- Що вже перевірено: SD-карта читається (ACT мигає), мережа працює; проблема зникла після заміни тільки джерела, без інших змін.
- Не перевірено: напруга на пінах 2/4 при живленні від ПК (замір мультиметром «до» не робився). Для повноти можна повторити з ПК і заміряти, але не під час запису на SD-карту.
- Урок для чек-листа: `vcgencmd get_throttled` — перша команда після підключення до будь-якої Pi; до `0x0` інші тести не запускати.
