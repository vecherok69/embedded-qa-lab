# День 1: живлення та GPIO на Raspberry Pi 3

Заповнюється під час практики. Кожен замір: що міряли, чим, де, очікування, факт, висновок.

## Стенд

- Плата: Raspberry Pi 3 Model B+ (за написом на платі; точну ревізію взяти з `cat /proc/device-tree/model`)
- ОС: Raspberry Pi OS Lite (64-bit), хост `pi3lab`, доступ по SSH через Wi-Fi 2,4 ГГц; ядро (`uname -a`):
- Блок живлення: окремий блок 5 В (струм уточнити за наклейкою), кабель micro-USB. Спочатку плата живилась від USB-порту ПК, див. [BUG-002](../bug-reports/BUG-002-pi3-undervoltage-pc-usb.md)
- Мультиметр: ANENG SZ08, режим DC V, межа 20 В; підключення до пінів через дроти Dupont мама-тато
- Дата: 2026-10-31

## Живлення

| ID | Що міряємо | Точки (пін ↔ пін) | Очікувано | Факт | Висновок |
| --- | --- | --- | --- | --- | --- |
| PWR-00 | `vcgencmd get_throttled` після завантаження, живлення від USB-порту ПК | — | `0x0` | `0x50005`, червоний PWR згасає після старту | ❌ undervoltage, [BUG-002](../bug-reports/BUG-002-pi3-undervoltage-pc-usb.md) |
| PWR-00a | те саме після заміни на блок 5 В | — | `0x0` | `0x0`, PWR світиться постійно | ✅ |
| PWR-01 | 5 В у простої | пін 2 ↔ пін 6 (GND) | 4,75–5,25 В | 5,00 В | ✅ |
| PWR-01a | 5 В у простої | пін 4 ↔ пін 6 | 4,75–5,25 В | 4,98 В | ✅ (та сама лінія, що й пін 2; різниця 0,02 В у межах похибки) |
| PWR-02 | 3,3 В у простої | пін 1 ↔ пін 6 | 3,14–3,47 В | 3,29 В | ✅ |
| PWR-02a | 3,3 В у простої | пін 17 ↔ пін 6 | 3,14–3,47 В | 3,30 В | ✅ |
| PWR-03 | 5 В під навантаженням (`stress` / `yes > /dev/null` ×4) | пін 2 ↔ пін 6 | не нижче 4,75 В | | |
| PWR-04 | `vcgencmd get_throttled` після навантаження | — | `0x0` | | |

Усі заміри PWR-01…PWR-02a зроблено з новим блоком живлення.

Розшифровка `get_throttled`: біт 0 — undervoltage зараз, біт 2 — тротлінг зараз, біт 16 — undervoltage був з моменту завантаження, біт 18 — тротлінг був. Наприклад `0x50000` = undervoltage і тротлінг були, але зараз немає; `0x50005` = є зараз і були раніше.

Помилка методики, знайдена під час замірів: перший замір «піна 17» показав ≈0,05 В. Причина: пін відраховано як 17-й у лівому ряду (насправді це пін 33, GPIO13 у стані LOW). Нумерація на роз'ємі йде парами через обидва ряди: зліва непарні, справа парні. Після виправлення пін 17 = 3,30 В. Висновок: перед тим як заводити дефект, перевірити саму методику вимірювання.

## GPIO

| ID | Перевірка | Як | Очікувано | Факт | Висновок |
| --- | --- | --- | --- | --- | --- |
| GPIO-01 | Вихід HIGH | GPIO17 = 1, мультиметр пін 11 ↔ GND | ≈3,3 В | | |
| GPIO-02 | Вихід LOW | GPIO17 = 0 | ≈0 В | | |
| GPIO-03 | Вхід без підтяжки, провід «в повітрі» | читати GPIO27 у циклі 100 разів | значення «плаває» | | |
| GPIO-04 | Вхід з pull-up | `pull_up=True`, вхід вільний | стабільно 1 | | |
| GPIO-05 | Вхід з pull-up, замкнути на GND | перемичка пін 13 ↔ GND | стабільно 0 | | |
| GPIO-06 | PWM 50 % | `PWMOutputDevice(17, frequency=1000, value=0.5)`, мультиметр DC V | ≈1,65 В (середнє) | | |

Примітка до GPIO-06: мультиметр показує середнє значення, а не форму сигналу. Частоту та скважність точно видно тільки осцилографом або логічним аналізатором.
