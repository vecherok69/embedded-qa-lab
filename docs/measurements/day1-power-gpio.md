# День 1: живлення та GPIO на Raspberry Pi 3

Заповнюється під час практики. Кожен замір: що міряли, чим, де, очікування, факт, висновок.

## Стенд

- Плата: Raspberry Pi 3 (модель/ревізія з `cat /proc/device-tree/model`):
- ОС, ядро (`uname -a`):
- Блок живлення: виробник, 5 В / ___ А, кабель:
- Мультиметр: модель, режим DC V:

## Живлення

| ID | Що міряємо | Точки (пін ↔ пін) | Очікувано | Факт | Висновок |
| --- | --- | --- | --- | --- | --- |
| PWR-01 | 5 В у простої | пін 2 ↔ пін 6 (GND) | 4,75–5,25 В | | |
| PWR-02 | 3,3 В у простої | пін 1 ↔ пін 6 | 3,14–3,47 В | | |
| PWR-03 | 5 В під навантаженням (`stress` / `yes > /dev/null` ×4) | пін 2 ↔ пін 6 | не нижче 4,75 В | | |
| PWR-04 | `vcgencmd get_throttled` після навантаження | — | `0x0` | | |

Розшифровка `get_throttled`: біт 0 — undervoltage зараз, біт 2 — тротлінг зараз, біт 16 — undervoltage був з моменту завантаження, біт 18 — тротлінг був. Наприклад `0x50000` = undervoltage і тротлінг були, але зараз немає.

## GPIO

| ID | Перевірка | Як | Очікувано | Факт | Висновок |
| --- | --- | --- | --- | --- | --- |
| GPIO-01 | Вихід HIGH | GPIO17 = 1, мультиметр пін 11 ↔ GND | ≈3,3 В | | |
| GPIO-02 | Вихід LOW | GPIO17 = 0 | ≈0 В | | |
| GPIO-03 | Вхід без підтяжки, провід «в повітрі» | читати GPIO27 у циклі 100 разів | значення «плаває» | | |
| GPIO-04 | Вхід з pull-up | `pull_up=True`, вхід вільний | стабільно 1 | | |
| GPIO-05 | Вхід з pull-up, замкнути на GND | перемичка пін 13 ↔ GND | стабільно 0 | | |
| GPIO-06 | PWM 50 % | `PWMOutputDevice(17, frequency=1000, value=0.5)`, мультиметр DC V | ≈1,65 В (середнє) | | |

Примітка до GPIO-06: мультиметр показує середнє значення, а не форму сигналу. Частоту та скважність точно видно тільки осцилографом або логічним аналізатором.
