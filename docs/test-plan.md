# Тест-план: I2C-датчик MPU6050 на Raspberry Pi Pico (симуляція Wokwi)

## Мета

Перевірити, що Pico коректно взаємодіє з датчиком MPU6050 по I2C: знаходить його на шині, читає WHO_AM_I і дані, поводиться передбачувано при несправностях.

## Стенд

- Raspberry Pi Pico, MicroPython (симулятор Wokwi)
- MPU6050: VCC → 3V3(OUT), GND → GND, SDA → GP16, SCL → GP17
- Логічний аналізатор Wokwi: D0 = SDA, D1 = SCL, GND; запис у PulseView з декодером I²C
- Код: `src/wokwi/02_i2c_mpu6050.py`

## Обмеження

Wokwi симулює логіку, а не струми й електричні ефекти. Дребезг, «плаваючий» вхід, просадки живлення і шуми перевіряються тільки на реальному залізі (Raspberry Pi 3 + мультиметр, див. `src/pi3/`).
